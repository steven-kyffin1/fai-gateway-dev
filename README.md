# zero-touch-emc-lvd

Authoritative gateway branch with focused EMC recovery, 3-second dwell-aware monitoring and the minimal AudioMoth USB recording function included in the test configuration.

Start with [EMC_RECOVERY_IMPLEMENTATION.md](EMC_RECOVERY_IMPLEMENTATION.md). For an existing gateway, use `scripts/install_recovery.sh`; do not rerun the full provisioning bootstrap solely to install these changes.
